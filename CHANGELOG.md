# Changelog

This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-07

First release.

### Added
- Tab search across all windows with keyboard navigation (Alt+Shift+T)
- Duplicate detection with a toolbar badge, one-click cleanup, and an optional switch-to-existing-tab mode
- Group by site, group rules with names and colours, and optional automatic grouping (Chromium)
- Automatic suspending of idle tabs using native tab discarding, with exclusions; "Suspend others" action
- Sessions: save and restore windows with pins and groups, lazy loading on restore, autosave snapshots, import and export
- Chromium and Firefox (experimental, no tab groups) builds
- Unit tests (11) and end-to-end tests with real tabs (19 checks), plus GitHub Actions CI and release workflows
